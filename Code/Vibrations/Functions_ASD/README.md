# Functions_ASD

This folder contains the helper and analysis functions used for the acceleration spectral density analysis.

The functions are split according to the dataset they refer to. `Functions_A.py` and `Functions_B.py` contain the dataset-specific functions for two different measurement datasets. The file `Functions_PSI.py` acts as a selection layer between them.
